# Contributing

Keep each change focused. Link an issue, state acceptance criteria and use a task branch/worktree. Test happy paths, invalid input, failure recovery and permission boundaries. Run `just check` and `just ci`; never use `--no-verify`.

Use Conventional Commits. Have a non-author review the final diff. Changes to CI, hooks, dependencies, authorization and release behavior need explicit maintainer review. Do not weaken tests to make a change pass. Release evidence must separate synthetic CLI fixtures from live model runs.

Do not upload your private Studio or original work logs. Use synthetic reproductions. By contributing you agree that your contribution is MIT licensed.
